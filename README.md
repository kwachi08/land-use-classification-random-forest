
# Land Use Classification from Satellite Imagery Using Random Forest

## Project Overview
This project uses a Random Forest classifier to classify satellite images into different land use and land cover categories using the EuroSAT dataset.

## Dataset
- EuroSAT RGB Dataset
- 10 land cover classes
- RGB satellite imagery

## Model
- Random Forest Classifier
- Accuracy: 57%

## Key Results
The model performed best on visually distinct classes such as:
- SeaLake
- Forest
- Industrial

Vegetation-related classes were more difficult to distinguish.
